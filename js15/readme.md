# Movie List App

This project displays a list of movies and their details, and allows users to search for movies by title.

## Files

- `movies.json`: The JSON file containing movie data.
- `movie.html`: The HTML file that structures the web page.
- `movie.js`: The JavaScript file that fetches and displays the movie data, and implements the search functionality.
- `styles.css`: (Optional) A CSS file to style the web page.

## Usage

1. Open `movie.html` in a web browser.
2. The page will display a list of movies.
3. Use the search bar to filter movies by title. Click the "Search" button to apply the filter.

## How it works

- The `fetch` method is used to retrieve data from `movies.json`.
- The movie data is then displayed as a list of movie titles, directors, and release dates.
- The search bar allows users to filter the list of movies based on the search input. The "Search" button triggers the filter.
