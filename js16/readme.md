# Product List

This project displays a list of products using data from an XML file and provides a search functionality to find products by name.

## Files

- `product.html`: The main HTML file that contains the structure of the webpage.
- `product.js`: The JavaScript file that handles parsing the XML file and managing the product table.
- `products.xml`: The XML file containing product data.
- `README.md`: This file, explaining the usage of the program.

## How to Use

1. Open `product.html` in a web browser.
2. The product list will be loaded from `products.xml` and displayed in a table.
3. Use the search bar at the top of the page to filter products by name.
